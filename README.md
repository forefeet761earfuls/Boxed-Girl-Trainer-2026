## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Boxed Girl**. This trainer streamlines Boxed Girl's choice-driven progression by helping manage daily route progress, interaction unlocks, item availability, and outfit access.

**Target Audience:** Players who want to explore Boxed Girl's branching daily routes, unlockable interactions, and outfits with less repetition.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Boxed Girl does not use conventional free-roaming movement. Progress is made through daily menus, location choices, and interactive Live2D sequences.

### Tools & Inventory

Items and actions are unlocked through route progression. Use the trainer after loading a save and before selecting a daily route if you want to modify unlock availability.

### World & Environment

Each day presents four route choices associated with different locations and themes. Repeating a route advances its unlock track, while completed unlocks remain available for later scenes.

### Combat & Weapons

Boxed Girl has no combat system. Its core gameplay consists of selecting routes, making choices, advancing daily sequences, and viewing the resulting interactive scenes.
